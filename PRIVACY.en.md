# Lunatide Privacy Policy

Lunatide requires no account and has no network access, ads, community, analytics or crash-upload service.

Periods, symptoms, mood, temperature, intercourse and notes that you enter are processed and stored only in this phone’s private app directory. Health records use a SQLCipher encrypted database. A key in Android Keystore protects its random database password. App settings are stored in private DataStore files.

Lunatide does not read device identifiers, contacts, location, camera, microphone or system health records. Optional reminders request notification permission. Biometrics are only a shortcut after you set an app PIN.

The PIN controls access to the interface and does not encrypt the database. Local reminder workers can read the database while the interface is locked. Notifications use neutral wording by default, with a neutral public version. Protection is limited on rooted or compromised devices, or when someone has access to an unlocked phone. Screenshot protection cannot prevent an external camera taking a photo.

System cloud backup and automatic device migration are disabled. Uninstalling deletes local app data. Before uninstalling or changing phones, export an encrypted backup and keep its password safe. Backup passwords cannot be recovered. Exported CSV files are not encrypted and anyone with the file can read them. You choose import and export locations in the system file picker, which may include cloud providers offered by other apps.

You can erase all local data in settings. Exported files outside the app are not deleted; remove them yourself. Lunatide does not check for updates. Visit the website or GitHub yourself to find updates.

Predictions use past records for reference only. They cannot be used for contraception and do not replace a medical diagnosis.
