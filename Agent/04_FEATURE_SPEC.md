# 04 · 功能需求详细说明

> 术语：**经期** = 一次例假（从开始日到结束日）；**周期** = 两次经期开始日之间的天数；**周期第 N 天** = 从本次经期开始日算起的第 N 天（开始日为第 1 天）。

## 0. 整体导航

- 底部导航 3 个 Tab：**今天** / **日历** / **统计**。
- 「设置」入口：今天页右上角齿轮图标。
- 每日记录编辑：在日历或今天页点击某天后，以 **ModalBottomSheet** 打开（可展开到全屏）。
- 应用锁开启时，冷启动和从后台返回（超过设定时长）先显示锁屏页。

## 1. 首次引导（Onboarding）

只在首次启动时出现；完成或跳过后写入 `onboardingCompleted = true`。每一页都有「跳过」。

| 页 | 内容 | 交互 |
|---|---|---|
| 1 欢迎 | Logo + 「月汐」+ 标语；三条承诺：①不用注册，打开就能用 ②数据只存在这台手机上，不联网 ③没有广告，也没有社区 | 「开始」 |
| 2 上次例假 | 「上次例假是哪天开始的？」日期选择（默认今天往前推，不允许选未来） | 「不记得了」可跳过 |
| 3 经期与周期 | 「一般持续几天？」步进器（2–10，默认 5）；「大概多久来一次？」步进器（20–45，默认 28）；每项都有「不确定」 | 不确定时使用默认值，并标记为“未知” |
| 4 安全与提醒（可选） | 「要给月汐加一把锁吗？」→ 设置 PIN（可跳过）；「需要在经期快来时提醒你吗？」→ 开启则在此时申请通知权限（Android 13+） | 「完成」 |
| 5 关于数据（一屏说明） | 「因为数据只存在这台手机上，卸载或换手机前请记得在『设置 → 备份』导出备份。」 | 「我知道了」 |

规则：
- 第 2 页填写了日期 → 创建一条经期记录：start = 所选日期，end = start + 经期天数 − 1（若 end ≥ 今天，则 end 为空表示“进行中”）。
- 第 3 页的值保存为用户初始值（见 `06_PREDICTION_ENGINE.md` 的冷启动策略），不是写死的历史数据。

## 2. 今天页（首页）

### 2.1 布局（自上而下）
1. 顶部：日期（如「10月24日 周六」）+ 右上角设置齿轮。
2. **状态主卡片**：中间一个圆环（周期进度，月相/潮汐视觉，见 `07_UI_UX_GUIDE.md`），圆环内是主文案，下方是副文案。
3. **主操作按钮**（大、醒目）：根据状态显示「例假来了」或「例假走了」。
4. 「今天的记录」卡片：显示今天已记录的经量/症状/心情摘要；没有记录时显示「记一下今天的感受」→ 点击打开今天的记录编辑。
5. 「接下来」小卡片：下次经期预测日期（含范围）、易孕期（若启用显示且周期规律）。
6. 底部极小字：「预测仅供参考，不能用于避孕」。

### 2.2 状态文案（主文案 / 副文案）

| 状态 | 判断 | 主文案 | 副文案 |
|---|---|---|---|
| 无任何记录 | periods 为空 | 「欢迎来到月汐」 | 「例假来的时候，点下面的按钮记一下就好」 |
| 经期中 | 今天落在某段经期内（含进行中） | 「经期第 N 天」 | 「预计还有 M 天左右结束」（M ≤ 0 时显示「快结束了吧？结束了记得点一下」） |
| 等待下次 | 不在经期，且今天 < 预测开始日 | 「距离下次经期约 N 天」 | 「预计 11月3日 开始（前后 ±X 天）」；仅有一个历史点时显示「记录越多，预测越准」 |
| 预测当天 | 今天 = 预测开始日 | 「经期可能今天开始」 | 「来了的话点一下下面的按钮」 |
| 推迟 | 今天 > 预测开始日且未记录新经期 | 「已推迟 N 天」 | N ≤ 7：「偶尔推迟几天很常见」；N > 7：「推迟较久了，如果还有其他不适，可以考虑咨询医生」 |

（「易孕期」状态不放主文案，避免让首页显得“备孕/避孕导向”；放在「接下来」卡片中。）

### 2.3 主按钮逻辑
- **不在经期** → 显示「例假来了」：点击后直接以**今天**为开始日创建经期（end 为空=进行中），并显示 Snackbar「已记录：今天开始 · 撤销 · 改日期」。「改日期」打开日期选择（不能选未来，不能早于上一段经期结束日）。
- **经期进行中** → 显示「例假走了」：点击后以今天为结束日，同样 Snackbar 支持撤销和改日期（结束日 ≥ 开始日，≤ 今天）。
- 若用户在距上次经期结束 < 10 天时点「例假来了」：弹确认框「距离上次经期才过了 N 天，确定是新的一次例假吗？」选项：「是，新的一次」/「只是少量出血（记为点滴出血）」/「取消」。选第二项则在今天的 DayLog 记 flow = SPOTTING，不创建经期。

## 3. 日历页

### 3.1 月视图
- 顶部：年月标题 + 左右切换箭头；支持左右滑动切月；「回到今天」按钮（不在当月时显示）。
- 一周起始日按设置（默认**周一**）。
- 日期格子的视觉状态（颜色+形状双重区分，不只靠颜色，见 `07_UI_UX_GUIDE.md`）：
  - 已记录经期：实心填充（玫瑰色）
  - 预测经期：虚线描边 + 浅色填充
  - 预测易孕期：浅青色底
  - 预测排卵日：青色小圆点/描边
  - 今天：加粗数字 + 外圈
  - 有记录（症状/心情/备注等）：日期下方小圆点
  - 点滴出血：小水滴图标
- 预测显示范围：从今天起往后**最多 6 个周期**；过去的日期不显示预测，只显示真实记录。
- 底部：图例（可折叠）+ 当月摘要（例如「本月经期：10月3日–10月8日，共 6 天」）。

### 3.2 点击日期
- 打开该日的**每日记录编辑**（Bottom Sheet）。
- 未来日期：只能查看预测说明（「预测经期第 2 天」「预测易孕期」），不能记录经量/症状（提示「还没到这一天哦」）。

## 4. 每日记录编辑（DayLog Sheet）

顶部：日期 +「这天在经期中」开关。

| 字段 | 控件 | 取值 | 说明 |
|---|---|---|---|
| 这天在经期中 | Switch | 是/否 | 改动它触发经期合并/拆分规则（见 `05_DATA_MODEL.md` §3） |
| 经量 | 5 档单选 Chip（可取消） | 点滴、少、中、多、很多 | 「点滴」可在非经期选择（= 点滴出血）；其他档在非经期选择时，提示「要把这天标为经期吗？」 |
| 痛经 | 4 档单选 | 不痛、轻微、明显、很痛 | |
| 症状 | 多选 Chip | 见下方列表 | |
| 心情 | 单选（图标+文字） | 开心、平静、低落、烦躁、焦虑、敏感 | 可取消 |
| 基础体温 | 数字输入 | 34.0–42.0 ℃，保留 2 位小数 | 默认折叠，设置里可隐藏 |
| 同房 | 单选 | 无保护、有保护 | **默认隐藏**，在「设置 → 记录项」开启后显示 |
| 备注 | 多行文本，≤ 500 字 | | 遵守 R9 输入法隐私 |

内置症状（code 稳定、显示名走字符串资源）：
`CRAMPS` 腹痛、`BACK_PAIN` 腰酸、`HEADACHE` 头痛、`BREAST_TENDERNESS` 乳房胀痛、`BLOATING` 腹胀、`ACNE` 长痘、`FATIGUE` 疲倦、`NAUSEA` 恶心、`DIARRHEA` 腹泻、`CONSTIPATION` 便秘、`INSOMNIA` 失眠、`CRAVINGS` 嘴馋、`DIZZINESS` 头晕、`DISCHARGE` 白带增多、`COLD_HANDS_FEET` 手脚冰凉。

交互：
- **自动保存**：每次改动后防抖 300ms 写库，无「保存」按钮；关闭 Sheet 时确保已写入。
- 所有字段为空且不在经期时，删除该日 DayLog 行（不留空行）。
- 「清空这天的记录」按钮（二次确认）。

## 5. 统计页

数据不足时（< 2 次经期）显示空状态：「再记录一次经期，就能看到你的周期统计啦」。

模块：
1. **概览卡片**（3 个数字）：平均周期（天）、平均经期（天）、规律性（规律 / 较规律 / 不太规律，定义见 `06_PREDICTION_ENGINE.md` §6）。
2. **周期长度柱状图**：最近 12 个完整周期，每根柱子标注天数；虚线标出平均值；正常参考范围 21–35 天用浅色背景带标示。用 Compose Canvas 自绘；支持 TalkBack 读出每根柱子。
3. **经期长度**：最近 12 次经期的长度（小柱状图或点图）。
4. **常见症状**：最近 6 个周期里出现最多的 5 个症状 + 次数；痛经程度分布。
5. **周期历史列表**：每行「2026.10.03 开始 · 周期 29 天 · 经期 6 天」，点击跳转日历对应月份。进行中的周期显示「进行中 · 第 N 天」。
6. 底部温和提示（仅在满足条件时显示，见 `06_PREDICTION_ENGINE.md` §6）。

## 6. 提醒

设置路径：设置 → 提醒。全部提醒共享一个「提醒时间」（默认 20:00），每项可单独开关。

| 提醒 | 默认 | 触发条件 | 隐私模式文案 | 详细模式文案 |
|---|---|---|---|---|
| 经期临近 | 开 | 预测开始日前 N 天（N 可选 1/2/3/5，默认 2） | 「月汐：最近几天记得照顾好自己」 | 「经期预计 2 天后开始，记得提前准备」 |
| 经期可能开始 | 开 | 预测开始日当天，且尚未记录 | 「月汐：今天有一条待确认的记录」 | 「经期可能今天开始，来了记得记一下」 |
| 记得记录结束 | 开 | 进行中的经期已持续 ≥ 平均经期长度 + 2 天 | 「月汐：有一条记录等你更新」 | 「这次经期已经 7 天了，结束了记得点一下」 |
| 每日记录 | 关 | 每天 | 「月汐：今天过得怎么样？」 | 同左 |
| 易孕期 | 关 | 预测易孕期第一天 | 「月汐：有一条新提醒」 | 「预测易孕期今天开始（仅供参考）」 |

技术规则：
- 通知渠道：`reminders`（默认重要性）。点击通知打开 App（经过应用锁）。
- 调度：WorkManager 一次性任务（`OneTimeWorkRequest` + `setInitialDelay` 到目标时刻），按提醒类型使用唯一任务名 `REPLACE`；在以下时机重新计算并调度：App 启动、任何经期/记录变更、提醒设置变更、每日一次的兜底 `PeriodicWorkRequest`。Worker 执行时**重新计算**条件，条件不满足就不发（例如用户已经记录了经期）。
- Android 13+ 在用户开启任一提醒时申请 `POST_NOTIFICATIONS`；被拒绝时在设置页显示「通知权限未开启」+「去系统设置」按钮。
- 国产 ROM 后台限制：在提醒设置页底部提供折叠说明「收不到提醒？」，指导用户允许自启动/关闭电池优化，并提供跳转 App 详情页（`Settings.ACTION_APPLICATION_DETAILS_SETTINGS`）的按钮。**不申请** `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 权限。
- 不使用精确闹钟（不申请 `SCHEDULE_EXACT_ALARM`），提醒时间允许有几分钟到十几分钟的偏差，在 UI 上不承诺精确到分钟。

## 7. 设置页

分组：
1. **周期**：平均周期长度（自动计算 / 手动指定）、平均经期长度（自动 / 手动）、显示易孕期和排卵日（开关，默认开）
2. **记录项**：显示基础体温、显示同房记录（默认关）、一周起始日（周一/周日）
3. **提醒**：见 §6
4. **隐私与安全**：应用锁（PIN）、指纹/面容解锁、自动锁定（立即/30 秒/1 分钟/5 分钟，默认立即）、防截屏和最近任务隐藏、通知隐私模式
5. **数据**：导出加密备份、从备份恢复、导出 CSV 表格、删除全部数据
6. **外观**：主题（跟随系统/浅色/深色）
7. **关于**：版本号、隐私政策（本地页面）、开源许可（本地页面，手写列出依赖及许可证，含 SQLCipher 的 BSD 风格许可，以及月汐本身的 MIT 许可）、健康声明、「月汐不联网」说明；「月汐不会联网检查更新，新版本请访问官网或 GitHub 查看」+ 官网地址 `https://xichugeek.com/projects/lunatide/` 和 `https://github.com/xichugeek/Lunatide/releases`（纯文本 + 复制按钮，见 `11_OPEN_SOURCE_AND_RELEASE.md` §2）

## 8. 删除全部数据

- 入口：设置 → 数据 → 删除全部数据。
- 二次确认：说明不可恢复，建议先导出备份；需要用户输入「删除」两个字才能点确认。
- 执行：关闭数据库 → 删除数据库文件及 `-wal`/`-shm` → 清空 DataStore → 删除 Keystore 中的密钥 → 取消所有 WorkManager 任务 → 回到首次引导。

## 9. 空状态、错误与边界

- 所有列表/图表都要有空状态设计（插画可用简单矢量图形）。
- 数据库无法解密（Keystore 密钥丢失，少数机型系统升级后会发生）：显示专门的恢复页，说明情况，提供「从备份恢复」和「重置并重新开始」，**不得静默清空数据**。
- 日期边界：跨年、闰年 2 月 29 日、用户修改系统日期（“今天”倒退）不崩溃。
- 大量数据：至少能流畅处理 20 年的记录（约 260 次经期、7300 条 DayLog）。
