# 07 · 视觉与交互规范

## 1. 设计关键词

**月夜、潮汐、安静、温柔、干净。** 不要满屏粉红，不要卡通少女风，不要花哨渐变和闪烁动效。目标感受：像一本放在床头的精致小日记本。

## 2. 配色（Material 3 自定义 ColorScheme）

默认**不启用**动态取色（Dynamic Color），保持品牌一致；可在 `DECISIONS.md` 讨论后作为设置项提供。

### 2.1 品牌与语义色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `primary`（月夜靛） | `#4B4A8C` | `#BDBBF2` | 主按钮、选中态、强调 |
| `onPrimary` | `#FFFFFF` | `#24234F` | |
| `background` | `#FBF8F6`（暖白） | `#14141C` | 页面背景 |
| `surface` | `#FFFFFF` | `#1C1C26` | 卡片 |
| `surfaceVariant` | `#F1ECEA` | `#2A2A36` | 次级卡片、输入框 |
| `onSurface` | `#1E1B22` | `#E8E4EC` | 正文 |
| `onSurfaceVariant` | `#6B6470` | `#A9A3B0` | 次要文字 |
| `period`（经期·玫瑰） | `#E0637A` | `#F08C9E` | 已记录经期 |
| `periodContainer` | `#FBE3E7` | `#4A2530` | 预测经期浅底 |
| `fertile`（潮汐青） | `#4FA3A5` | `#7CC9CB` | 易孕期 |
| `fertileContainer` | `#DDF1F1` | `#1F3D3E` | 易孕期浅底 |
| `ovulation` | `#2E7D80` | `#A5E0E1` | 排卵日标记 |

要求：所有文字与背景对比度 ≥ 4.5:1（大字 ≥ 3:1），实现后用 Compose 预览在浅/深色下逐一检查。

### 2.2 不只靠颜色区分（色弱友好）

| 状态 | 颜色 | 形状/图形 |
|---|---|---|
| 已记录经期 | `period` 实心圆底 | 白色日期数字 |
| 预测经期 | `periodContainer` 浅底 | **虚线**圆形描边 |
| 易孕期 | `fertileContainer` 浅底 | 无描边 |
| 排卵日 | `ovulation` | 实线描边 + 右上角小星点 |
| 今天 | `primary` | 粗体数字 + 底部短横线 |
| 点滴出血 | `spotting` | 小水滴图标 |
| 有其他记录 | `onSurfaceVariant` | 数字下方小圆点 |

## 3. 字体与排版

- 使用系统默认字体（中文自动用系统中文字体），不打包字体文件。
- 字号使用 Material 3 Typography；今天页主文案用 `headlineMedium`，大数字（如「12」天）用 `displayMedium` 并配 `FontFeature` 等宽数字（`tnum`）。
- 支持系统字体放大到 200% 不截断、不重叠（布局用 `wrapContentHeight`，避免写死高度）。

## 4. 形状、间距、动效

- 卡片圆角 20dp，按钮圆角全圆（`CircleShape`/`50%`），BottomSheet 顶部 28dp。
- 间距基准 4dp；页面左右边距 20dp；卡片间距 12–16dp。
- 点击区域 ≥ 48dp。
- 动效克制：页面切换用淡入淡出/轻微位移（≤ 250ms）；圆环进度变化用 600ms 缓动；尊重系统「移除动画」设置。
- 首页「例假来了」点击后：按钮轻微缩放回弹 + 触感反馈（`HapticFeedbackType.LongPress` 或 `Confirm`），不放彩带、不放烟花。

## 5. 关键组件

### 5.1 今天页周期圆环（品牌核心视觉）
- 一个细圆环（stroke 10–12dp），代表整个周期 C 天；从 12 点方向顺时针。
- 经期段用 `period` 色，易孕期段用 `fertile` 色，其余为 `surfaceVariant`。
- 当前日位置有一个小圆点（「月亮」），圆点可以根据周期阶段呈现月相（新月→满月→残月）——做成简单的矢量绘制即可，不要复杂插画。
- 圆环中间显示主文案与大数字。
- 推迟状态：圆环满一圈后，超出部分用 `periodContainer` 虚线继续。
- 需要 `contentDescription`，例如「周期第 12 天，距离下次经期约 16 天」。

### 5.2 日历格子
- 尺寸自适应宽度（7 列等分），高度 ≥ 48dp。
- TalkBack 读法：「10月3日，星期五，经期第2天，已记录经量中等」；「11月2日，预测经期」；「10月18日，预测排卵日」。

### 5.3 PIN 键盘
- App 自绘 3×4 数字键盘（1–9，左下「指纹」图标（若可用），0，右下删除）。
- 圆点指示已输入位数；输错时圆点左右抖动 + 触感反馈。
- 不显示数字本身；按键不播放系统按键音。

### 5.4 Chip 选择
- 经量 5 档可用水滴图标大小/填充程度体现（空心小 → 实心大），同时有文字。

## 6. 文案语气

原则：**像一位体贴、懂医学常识、但不唠叨的朋友。** 平视、简短、温柔，不说教，不制造焦虑。

| ✅ 这样写 | ❌ 不要这样写 |
|---|---|
| 「经期第 3 天」 | 「亲~今天是大姨妈第 3 天哦~」 |
| 「已推迟 4 天。偶尔推迟几天很常见」 | 「警告！月经推迟，可能怀孕或内分泌失调！」 |
| 「记一下今天的感受」 | 「快来打卡！连续记录 7 天解锁勋章」 |
| 「如果有疑虑，可以咨询医生」 | 「你可能患有多囊卵巢综合征」 |
| 「数据只存在这台手机上」 | 「我们非常重视您的隐私安全」（空话） |

- 用「例假」「经期」，不用「大姨妈」「姨妈」等俗称（避免轻佻）；也不用过于医学的「月经」作为主文案（「月经」可出现在说明文字中）。
- 不用感叹号堆砌，不用颜文字/emoji 作为界面文字。
- 数字与汉字之间加空格：「约 16 天」。
- 所有界面文字放 `strings.xml`，**禁止硬编码**；复数/数量用 `plurals`（英文需要）。

## 7. 图标与启动

- 应用图标：深靛色背景上的**一弯新月 + 一道波浪线**（月 + 汐），简洁几何风格，矢量绘制（`adaptive-icon`，含 `monochrome` 图层以支持 Android 13 主题图标）。
- 桌面显示名：「月汐」（英文环境 “Lunatide”）。
- 启动页使用 `core-splashscreen`：背景 `background` 色，中间图标，不加广告位，不停留（数据就绪即进入）。

## 8. 无障碍清单

- 所有图标按钮有 `contentDescription`。
- 所有可交互元素 ≥ 48dp。
- 字体放大 200% 可用。
- TalkBack 能完成核心流程：记录例假开始/结束、打开某天记录、修改经量。
- 深色模式下无「白底闪屏」。
- 不只靠颜色传达信息（见 §2.2）。

## 9. 屏幕适配

- 手机竖屏为主；横屏和大屏（折叠屏/平板）不崩溃、不拉伸变形：内容区最大宽度 600dp 居中。
- 支持 edge-to-edge（`enableEdgeToEdge()`），正确处理状态栏/导航栏/输入法 insets。
