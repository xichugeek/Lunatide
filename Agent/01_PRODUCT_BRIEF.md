# 01 · 产品概述

## 1. 背景与痛点

当前用户在用国内某主流经期 App 记录例假，遇到这些问题：

| 痛点 | 具体表现 | 月汐的对策 |
|---|---|---|
| 广告多 | 开屏广告、信息流广告、电商导购，打开 App 只想记一下却要先看广告 | **完全没有广告**，也不接入任何广告 SDK |
| 社区骚扰 | 评论区、私信、社区内容推送，有陌生人骚扰 | **没有社区、评论、私信、内容推送**，App 里没有任何「其他人」 |
| 强制注册 | 需要手机号注册登录 | **不需要注册**，装上就能用，没有账号这个概念 |
| 隐私担忧 | 经期、同房、身体状况等极私密数据上传到服务器 | **不联网**（连网络权限都不申请），数据加密存在手机本地 |
| 功能臃肿 | 大量和记录无关的功能（商城、课程、问答） | 只做**记录 + 预测 + 提醒 + 统计**，简单好用 |

## 2. 目标用户

- 主要用户：需要记录经期的女性，年龄 16–45，安卓手机（国内各品牌：华为/荣耀、小米、OPPO、vivo、三星等）。
- 用户特征：不一定懂技术；在意隐私；对广告和骚扰反感；希望打开就能用、几秒内完成记录。
- 典型场景：
  1. 例假来了，打开 App 点一下「例假来了」，3 秒完成。
  2. 想知道下次大概什么时候来，打开首页一眼看到。
  3. 出门前收到提醒「经期可能 2 天后开始」，提前准备。
  4. 去看医生时，打开统计页给医生看最近半年的周期。
  5. 换手机时，导出加密备份文件，用微信/数据线传到新手机导入。

## 3. 产品原则（排序即优先级）

1. **隐私第一**：能不收集就不收集，能本地就本地，能加密就加密。
2. **安静**：没有广告、推送营销、红点诱导、弹窗打扰。App 只在用户需要时出现。
3. **简单**：核心操作（记录经期开始/结束）在首页一步完成。
4. **可信**：预测要诚实地标注不确定性，健康提示要克制、不吓人、不卖焦虑。
5. **好看**：温柔、干净、有质感，不是一片粉红的刻板「少女风」。

## 4. 功能范围

### 4.1 v1.0 必做（MVP）

- 首次引导：隐私承诺 + 可选填写基础周期信息（可全部跳过）
- 今天页（首页）：当前状态（经期第几天 / 距离下次经期几天 / 已推迟几天），一键「例假来了 / 例假走了」
- 日历：月视图，区分已记录经期、预测经期、预测易孕期、预测排卵日；点某天可编辑当天记录
- 每日记录：经量、痛经程度、症状、心情、基础体温、同房（默认隐藏，可在设置中开启）、备注
- 周期预测：下次经期、经期长度、易孕期/排卵日（附带「仅供参考，不能用于避孕」声明）
- 统计：平均周期、平均经期、周期规律性、近 12 个周期柱状图、症状统计、周期历史列表
- 提醒：经期临近、经期可能开始、记得记录结束、每日记录（可选）、易孕期（可选）；通知内容可设为「隐私模式」
- 应用锁：独立 PIN（4–6 位）+ 可选指纹/面容；自动锁定时间；防截屏/最近任务模糊
- 备份：导出**加密**备份文件、从备份恢复（覆盖或合并）、导出 CSV（明文，有警告）
- 清除全部数据
- 设置：周期参数、一周起始日、主题（浅色/深色/跟随系统）、关于、隐私政策、开源许可

### 4.2 v1.1 及以后（本期不做，但架构上不要堵死）

- 自动定期备份到用户选择的手机文件夹（通过 SAF 持久化授权，仍然不联网）
- 桌面小组件（显示「距离下次 N 天」，支持隐私模式）
- 伪装图标（把桌面图标和名字换成中性的「便签」「日程」等，使用自绘图标，不仿冒任何品牌）
- 农历日期显示
- 自定义症状标签
- 从 CSV 导入

### 4.3 永远不做

- 账号、登录、注册、云同步、任何服务器
- 广告、推广、电商、会员付费、打赏入口
- 社区、评论、私信、分享到社交平台的「战绩卡片」
- 数据统计/埋点/崩溃上报 SDK（包括 Firebase、友盟、Bugly、Sentry 等）
- 加载远程内容的 WebView
- AI 聊天/在线问诊

## 5. 成功标准

- 新用户从安装到完成第一次记录 ≤ 30 秒（跳过引导时 ≤ 10 秒）。
- 记录「例假来了」从打开 App 到完成 ≤ 2 次点击（不含应用锁解锁）。
- 在系统设置里查看 App 权限，看不到网络、存储、位置、通讯录等任何敏感权限。
- release APK 体积目标 ≤ 15 MB（SQLCipher 原生库占大头，可接受）。
- 冷启动到可交互 ≤ 1.5 秒（中端机）。

## 6. 健康相关声明（必须在 App 内展示）

- 「月汐的预测基于你的历史记录，仅供参考，不能用于避孕，也不能替代医生的诊断。」
- 出现明显异常时（见 `06_PREDICTION_ENGINE.md` 的规律性提示），只做温和提示「如果持续出现这种情况，可以考虑咨询医生」，**不做任何诊断性表述**（不说「你可能患有 XX」）。
